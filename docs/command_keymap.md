# Command Keybindings

During command mode all keystrokes are directed to the command input. Normal
navigation is suspended until the command is run or cancelled.

| Key | Action |
| --- | --- |
| type | write the command |
| `tab` | accept suggestion |
| `enter` | run the command |
| `↑` | previous suggestion |
| `↓`/`tab` | next suggestion |
| `esc` | cancel |

See [docs/commands.md](commands.md) for the full list of available commands.
