# Settings Keybindings

| Key | Action |
| --- | --- |
| `↑`/`k`/`w` | move up |
| `↓`/`j`/`s` | move down |
| `tab` | toggle focused row |
| `enter` | close and keep changes |
| `S` | save defaults to config file |
| `r` | reset to defaults |
| `esc` | revert and cancel |

For rows that open a picker (group, notify level, notify timeout) use `enter`
to select the row, `↑`/`↓` to navigate the picker, `enter` to confirm and
`esc` to cancel.
